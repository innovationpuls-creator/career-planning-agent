## 概述

将 home-v2 首页从 1,791 行单体文件拆分为 6 个子组件 + 1 个数据获取 hook，全面采用 Claude 设计语言。页面整体约 193 行，仅负责数据编排和子组件组合。

### 2026-05-04 功能保全补修

- `useHomeData` 恢复并行读取 `currentUser`、收藏列表和最新能力分析；首页主数据失败才进入错误态，辅助请求失败时保留首页可用。
- `已匹配岗位数量` 改为优先使用收藏列表数量，收藏为空时回退到当前 active target。
- 个人信息卡补充展示 `学历` 和 `目标岗位`；编辑资料 Modal 补充简历图片上传，提交时随 `image_files` 进入 `/api/user-profile/onboarding`。
- 默认 5 步管线中的“职业匹配”跳转改为独立页 `/career-match`。

## UmiJS 测试基础设施问题与解决方案

### 问题: `jest.mock()` 触发 babel 预转换导致 `React is not defined`

UmiJS (`@umijs/test`) 对含 `jest.mock()` 的文件执行两步转换：

1. **Babel**: 仅 `@babel/plugin-transform-modules-commonjs`（将 ESM import 转为 CJS require），不包含 JSX transform
2. **esbuild**: `format: "cjs"`, `target: "es2019"`，处理 JSX

Babel 预转换会删除未使用的 `import React from 'react'`，导致 esbuild 阶段 JSX 的 `React.createElement` 无法解析。

### 解决方案

| 场景                       | 方案                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------ |
| framer-motion mock         | `__mocks__/framer-motion.js` 手动 mock，使用 `React.createElement`（无 JSX）                           |
| API 依赖组件 (ProfileCard) | 可选 props 注入 (`saveProfile`, `loadJobOptions`)，测试通过 props 传入 mock 函数，不使用 `jest.mock()` |
| 测试文件                   | 移除所有 `jest.mock('framer-motion')` 内联调用，改用手动 mock                                          |
