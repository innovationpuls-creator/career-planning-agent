A. 暖色职业导师

保留 Claude 纸感与 serif 气质，console 作为“智能体正在准备工作台”的活体证据。推荐默认方向。

agent // career-planning-engine

[加载] 简历解析引擎 ✓
[工具] 技能差距分析 ✓
[预热] 神经网络推理引擎 ✓
[加载] 岗位JD语料库 ✓

B. 智能控制台

更强科技感和动态感，左侧 console 是主视觉。冲击力强，但会比现有 Claude 暖色系统更硬。

登录后继续生成你的职业画像
├─ 岗位匹配引擎 ✓
├─ 成长路径规划 ✓
└─ 行业薪资数据库 ✓

C. 混合智能实验室

左侧有温暖叙事，也有 console 和微型系统卡片。现代感更强，但实现和视觉治理要更克制。

问题 1：你希望登录页第一眼更接近 A、B 还是 C？也可以点一个，再在终端补一句“更暖/更酷/console 再多一点”。
